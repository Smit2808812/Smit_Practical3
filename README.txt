HOW TO RUN
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open grid.html and choose Open with Live Server, or double-click the HTML file.
4. Use the navigation links to open all three practical pages.

Note: Bootstrap page loads Bootstrap 5.3.3 from a CDN, so internet access is needed for Bootstrap styling and the mobile navigation toggle.
